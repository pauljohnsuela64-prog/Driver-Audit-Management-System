# BHLI Audit Android foundation

Read-only Flutter client for authenticated ADMIN and AUDITOR accounts. Browse
shared active audits, search/filter/sort, paginate and inspect historical details.
Tokens and audit data remain in memory; remote APIs require trusted HTTPS.

See [development and disposable demo instructions](../docs/ANDROID_DEVELOPMENT.md),
[pinned toolchain setup](../docs/ANDROID_TOOLCHAIN.md) and
[verification evidence](../docs/ANDROID_VERIFICATION.md).

No Android audit mutations, account administration, offline cache or signed
distribution are included in Phase 4A.
